# Version Tracking

This file tracks version changes according to Semantic Versioning 2.0.0 (https://semver.org/)

## Current Version: 3.2.1

## Versioning Guidelines

Given a version number MAJOR.MINOR.PATCH, increment the:
- MAJOR version when you make incompatible API changes
- MINOR version when you add functionality in a backward compatible manner
- PATCH version when you make backward compatible bug fixes

## Version History

### v3.2.1 - 2026-01-05
**Type:** PATCH (Bug fix - prevents hanging on network issues)

**Changes:**
- Added timeout support for git operations to prevent indefinite hanging
- `--timeout` flag for `update` command (default: 300 seconds / 5 minutes)
- `--timeout` flag for `clone` command (default: 600 seconds / 10 minutes)
- Automatic process termination when timeout is reached
- Clear error messages when operations timeout
- Added wait-timeout dependency (v0.2)
- All network git operations now respect timeout settings
- Push operations use 5-minute timeout by default
- Quick local operations (status, init, rollback) use no timeout

**Files Modified:**
- Cargo.toml: Updated version to 3.2.1, added wait-timeout dependency

### v3.2.0 - 2026-01-05
**Type:** MINOR (Added functionality with some breaking changes to command names)

**Changes:**
- Added parallel execution support for `update` and `clone` commands via `--parallel` flag
  - Uses Rayon for efficient multi-threading
  - Sequential execution remains the default for safety
- Merged `parse-html` functionality into `clone` command
  - `clone --input <html-file>` now parses HTML and clones in one step
  - Optional `--output` flag to save extracted links
- Breaking: Renamed `clone-links` command to `clone`
- Breaking: Renamed `commit-push` command to `push`
- Breaking: Removed standalone `parse-html` command (merged into clone)
- Refactored clone functionality into modular helper functions
- Added rayon dependency (v1.10)
- Updated README with new command names and parallel execution examples
- Updated installation paths to reference scripts/ directory

**Files Modified:**
- Cargo.toml: Updated version to 3.2.0, added rayon dependency
- src/main.rs: Implemented parallel execution, renamed commands, merged parse-html into clone
- README.md: Updated command names, added parallel execution examples, updated install paths
- CHANGELOG.md: Added v3.2.0 entry with breaking changes

**Files Added:**
- None (all changes were modifications)

**Migration Guide:**
- Replace `hephaestus clone-links` with `hephaestus clone --links`
- Replace `hephaestus commit-push` with `hephaestus push`
- Replace `hephaestus parse-html -i file.html` with `hephaestus clone -i file.html` (if you want to clone after parsing)
- Add `--parallel` flag to `update --all` or `clone` for concurrent operations

## Next Version Planning

When planning the next version, consider:
- Bug fixes only → increment PATCH (e.g., 3.1.0 → 3.1.1)
- New features, backward compatible → increment MINOR (e.g., 3.1.0 → 3.2.0)
- Breaking changes, API changes → increment MAJOR (e.g., 3.1.0 → 4.0.0)
